# Skin Library (Fabric, Minecraft 1.21.11, только клиент)

Библиотека скинов для серверов со SkinRestorer.

- Пауза (Esc) -> кнопка «Библиотека скинов» слева сверху.
- «+ Добавить скин»: вставьте `/skin url "https://minesk.in/..." classic` -> справа появится 3D-превью.
- В карточке библиотеки стрелка ▶ внизу справа отправляет команду на сервер (скин надевается сразу).
- «Генератор команды»: ссылка или PNG-файл (кнопка «Обзор...» открывает проводник, файл можно и перетащить в окно) -> готовая команда. Файл загружается через сервис SkinsRestorer (Axolotl) / MineSkin, как на skinsrestorer.net/upload.
- Превью понимает ссылки `https://minesk.in/...`, `skinsrestorer-axolotl://...` и прямые ссылки на PNG.

## Файлы
- `config/skinlibrary/skins.json` — библиотека.
- `config/skinlibrary/config.json` — необязательный `mineskinApiKey` (используется только если загрузка через Axolotl не сработает).

## Возможности библиотеки
- Избранное (★), поиск по названию и тегу, фильтр «все / избранное / по тегу или папке», сортировка.
- Редактирование названия, тега и избранного — кнопка ✎ на выбранной карточке.
- «По нику» — скин игрока через API Mojang. Такой скин «живой»: когда игрок меняет скин, запись обновляется (при открытии библиотеки и перед надеванием).
- Импорт/экспорт библиотеки в JSON (кнопки слева внизу).
- Модель в превью можно вращать мышью (зажмите левую кнопку на модели); позы: стоит, идёт, машет.
- Звуки при наведении, выборе и надевании (переключатель «Звук»).
- Компактную кнопку с иконкой-головой в меню паузы (при наведении раскрывается) можно перетащить: зажмите и потяните. Позиция запоминается
  (`buttonX`, `buttonY` в `config/skinlibrary/config.json`).

## Меню, импорт, звуки, папки
- В главном меню и меню паузы слева — превью скина (последний надетый, иначе скин аккаунта). Тяните за пиксельную платформу, модель вращается мышью.
  Кнопка-иконка и превью не заезжают на кнопки меню и друг на друга. Кнопка «Меню-превью» в библиотеке включает/выключает превью.
- Автоимпорт: скин лицензионного аккаунта, официальный лаунчер (launcher_custom_skins.json, название берётся из файла),
  Prism/PolyMC/MultiMC (accounts.json и папка skins), Modrinth App/TLauncher/GDLauncher (папки skins), а также ваши папки («Импорт...» → «Добавить папку...»).
  Каждый лаунчер попадает в свою папку. У скинов из файлов ссылка для команды создаётся при первом надевании.
- Кнопки «Надеть», ★, ✎ и «x» стоят под полкой и не двигаются вместе с анимацией.
- Звуки: «Звуки анимаций» (Книги — страницы, Веер — стук планок, Волна — переливы, Карусель — щелчки) и независимые темы звуков
  (Классика, Кристалл, Мелодия, Ретро, Свои). Свои звуки (.ogg/.wav до 3 с) — «Звуки...» → «Импорт...».
- Папки: «Папки...» (создать, переименовать, удалить, открыть), фильтр «Папка» и выбор папки в окне ✎.

## Папки слева и размер превью
- Слева в библиотеке — панель папок в виде полупрозрачных папок Windows: из каждой торчат три карточки скинов, имя снизу.
  «Все скины», «Избранное», ваши папки и папки лаунчеров; клик открывает папку, колёсико над панелью прокручивает её.
  Плитка «Новая папка» открывает управление папками; кнопка ▤ в ряду под полкой перекладывает скин в следующую папку.
- Превью в меню стало чуть меньше (85%) и меняет размер как окно: тяните за любой из четырёх углов (55–150%).

## Новое в этой версии
- Исправлено: позы/анимации скинов в карточках не работали у скинов из мини-папок (общая текстура перерисовывалась мини-превью). Теперь у каждого места показа своя текстура.
- 9 поз: стоит, идёт, бежит, машет, танцует, сидит, крадётся, зомби, полёт.
- Плащи SkinsRestorer: внизу окон «Добавить», «Генератор», «По нику» и ✎ — полка крупных карточек с плащами, как карточки скинов: каждый плащ вращается вокруг своей оси, листание стрелками и колёсиком (на низком окне — кнопка «Плащ» и экран с такими же карточками).
  Скин с плащом создаётся через прокси Axolotl при первом надевании (или сразу в генераторе).
- Автонадевание: скин, выбранный в главном меню, применяется при входе на сервер и смене сервера — только если на сервере есть команда /skin
  (SkinRestorer) и этот скин ещё не надет на этом сервере. Включается в «Настройки...».
- КД 30 секунд между надеваниями (`wearCooldown` в config.json). Кнопка «Надеть» показывает обратный отсчёт.
- Надевание по клику на карточку / по кнопке / оба режима: «Настройки...».
- Звуки: вкладки «Общие», «Отдельные» (вкл/выкл и ползунок громкости для каждого звука), «Свои».
- Пасхалка: быстро кликните 5 раз по заголовку «Библиотека скинов» (за 2,5 секунды) — появится автомат с рычагом. Только внутриигровые очки.

## Оптимизация и надёжность
- Скачанные скины кэшируются на диске (`config/skinlibrary/cache`), загрузка идёт в ограниченном пуле из 3 потоков.
- Анимированное превью обновляется ~30 раз в секунду; рендер модели без лишних выделений памяти (≈0,7 мс на кадр).
- Конфиг и библиотека пишутся через временный файл; повреждённый файл сохраняется как `*.broken`.
- Позы подогнаны по размеру: ни одна поза не обрезается при вращении.
- Исправлено: устаревший фильтр папки после переименования/удаления, дубликаты скинов при добавлении.

## Ещё новое
- **Случайный скин:** кнопка ⚄ в ряду под полкой надевает случайный скин из текущего списка. В «Настройки...» можно включить
  «случайный скин при каждом входе» или «скин дня» (один и тот же в течение суток), а также выбрать папку, из которой брать скин.
  Применяется только на серверах с SkinRestorer, с учётом КД.
- **Перетаскивание карточек:** потяните выбранную карточку за нижнюю полосу с названием (или за любое место с зажатым Shift) на папку слева:
  «Все скины» убирает из папок, «Избранное» добавляет в избранное, плитка «Новая папка» создаёт папку.
- **Английский язык:** «Настройки...» → «Язык / Language»: Авто (по языку игры: русский или английский) / Русский / English.
  Словарь — `I18n.java`.
- **Уведомление о конце КД:** когда снова можно менять скин, в углу экрана появляется уведомление со звуком (можно отключить в настройках).

## Гайд и логотип
- При первом запуске в главном меню плавно открывается гайд (12 страниц с живыми анимированными макетами интерфейса):
  карточки с перелистыванием и переключением стилей, добавление скина, генератор/ник/импорт, надевание и КД, сервер и автонадевание,
  папки и перетаскивание, плащи, позы, превью в меню, темы и звуки, настройки. Демо безопасны: команды на сервер не отправляются.
- Открыть гайд снова: кнопка «?» в правом верхнем углу библиотеки или «Настройки...» → «Открыть гайд».
- Логотип: `src/main/resources/assets/skinlibrary/icon.png` (виден в списке модов).

## Обновление: плавность, плащи, диагностика
- Превью в меню движется плавно: пружинное следование за мышью, лёгкий наклон по инерции, отскок при отпускании, плавное изменение размера.
  Вращение модели мышью продолжается по инерции.
- PNG перед загрузкой приводятся к 64x64 (старые 64x32 и HD-скины конвертируются).
- Загрузка скина с плащом: имена полей формы Axolotl берутся из его OpenAPI (`/openapi`) автоматически; ошибки сервера показываются текстом.
- Ответ SkinRestorer на команду показывается уведомлением, чтобы было видно, почему скин не наделся.
- В гайде добавлен скин «Golem» (`assets/skinlibrary/demo_skin.png`).
